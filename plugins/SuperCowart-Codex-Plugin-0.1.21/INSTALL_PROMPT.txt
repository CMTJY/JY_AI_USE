1. 检查 plugins/supercowart/.codex-plugin/plugin.json 与 package.json。
2. 确认 Node.js 20.19.0 或更高版本以及 npm 可用。

5. 将这个包根目录注册为非默认本地 marketplace；marketplace 名为 supercowart-portable。若尚未注册，运行 codex plugin marketplace add "<包根目录绝对路径>"。
6. 运行 codex plugin add supercowart@supercowart-portable 安装或刷新插件。
7. 确认至少能发现 render_cowart_canvas_widget、edit_cowart_canvas、get_cowart_canvas_state、insert_cowart_html_draft 和 insert_cowart_image。
