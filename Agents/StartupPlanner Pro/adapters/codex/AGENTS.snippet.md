# StartupPlanner Pro v3 — Codex 入口

当用户明确要求使用 StartupPlanner Pro，或任务需要跨领域专业协作时：

1. 读取 `Agents/StartupPlanner Pro/core/BOOTSTRAP.md`；
2. 按 Bootstrap 渐进读取注册表、命中角色和技能，不全量加载；
3. 复杂且可独立拆分的任务优先使用 Codex 原生子 Agent；
4. 当前环境没有原生委派能力时，标记“单 Agent 串行角色模拟”；
5. 最终说明实际使用的角色、技能、验证和委派状态。

本片段应合并到目标项目根目录 `AGENTS.md`，不要复制团队业务规则。
