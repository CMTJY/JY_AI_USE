# 营销方法论：数据驱动与实验优化

> 状态：已收录（主控原创整理，2026-08-07）
> 来源：增长实验、数据分析与投放优化实践

## 一、一句话总结

不靠感觉做营销：用指标定义目标、用归因解释结果、用实验验证假设，把每一次投放和运营都变成可学习的资产。

## 二、底层逻辑

- 可衡量才能优化：没有指标就没有决策依据；
- 一切营销动作本质都是假设（“这样做会提高转化”），实验是验证假设成本最低的方式；
- 归因决定预算流向：不知道钱从哪个渠道赚回来的，就无法放大；
- 小步快跑、赢家放大、输家止损：单次失败也是数据资产。

## 三、核心框架

### 1. 指标体系（OSM）

- Objective 目标：一句话说清业务目标；
- Strategy 策略：达成目标的关键动作；
- Measure 度量：每个动作对应的可衡量指标；
- 顶层设北极星指标，向下拆到渠道、人群、素材粒度。

### 2. 渠道归因

- 统一口径：首触、末触、多触点线性或时间衰减，至少先统一一个口径；
- 按渠道记账：成本、曝光、点击、转化、收入、ROI/ROAS；
- 用标记链接（UTM 等）保证数据可追溯，不依赖估算。

### 3. A/B 实验流程

1. 提出假设：改什么、预期影响哪个指标、为什么；
2. 设计实验：单一变量、分组、样本量、实验时长；
3. 执行与监控：避免“测试中途偷偷改方案”；
4. 判定：看显著性，不看“感觉好像有效”；
5. 落地：有效则放大，无效则记录并止损。

### 4. 复盘四步

- 结果：实际数据 vs 预期；
- 归因：什么导致结果（渠道、素材、人群、时机、外部因素）；
- 洞察：可复用的规律；
- 行动：下一步做什么、不做什么。

## 四、适用场景与边界

- 适用：有一定流量与数据量的投放、运营、增长场景；
- 不适用：冷启动无数据阶段（先做定性研究和小样本验证，不要强行造实验）；样本太小就下结论（结果是噪声）；
- 注意：数据会说谎——口径不统一、样本不足、只看虚荣指标都会误导。

## 五、常用指标与检查项

- 北极星指标、漏斗转化率、CAC、LTV、ROI/ROAS；
- 实验置信度、显著性水平、提升幅度；
- 检查：每个关键指标是否有统一定义与来源？每次投放是否可归因？每个实验是否满足单一变量？

## 六、与其他方法论的关系

- 数据是增长飞轮的仪表盘（配合增长飞轮法）；
- 替代物性价比法里的锚点、竞品数据都要用数据核实；
- 任何方法论的效果都用数据驱动法验证。
