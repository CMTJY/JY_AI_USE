# v3 路由与调试指南

## 五阶段路由

槽位提取 → 复合任务拆分 → 候选召回 → 硬过滤 → 评分与冲突裁决。

评分维度：任务类型 30%、能力 25%、领域 15%、产物 15%、渠道 10%、生命周期 5%。规则详情在 `registry/routes.yaml` 与 `core/routing.md`。

## 边界示例
