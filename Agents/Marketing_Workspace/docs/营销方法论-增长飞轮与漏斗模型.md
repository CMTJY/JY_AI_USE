# 营销方法论：增长飞轮与漏斗模型

> 状态：已收录（主控原创整理，2026-08-07）
> 来源：AARRR/RARRA 模型、增长黑客实践与私域运营经验

## 一、一句话总结

把“获客 → 激活 → 留存 → 复购 → 转介绍”做成系统化、可复利的增长引擎：漏斗看单次转化，飞轮看长期复利。

## 二、底层逻辑

- 收入 = 流量 × 转化率 × 客单价 × 复购频次：四个杠杆任一放大都能带来增长；
- 漏斗是视角：每一环都会漏人，优化任一环都能直接提升结果；
- 飞轮是机制：留存用户带来复购，满意用户带来转介绍，转介绍带来更便宜的流量，每一圈都让下一圈更快；
- 北极星指标：唯一能反映产品给用户带来核心价值的指标，增长动作都围绕它。

## 三、核心框架

### 1. 确定北极星指标

- 订阅制产品用“周活跃订阅用户”，电商用“周复购订单”，内容号用“有效阅读时长”；
- 北极星必须反映用户价值，而不是虚荣指标（如注册数）。

### 2. 增长等式拆解

- 写出收入公式，逐项标注现状、瓶颈、优化空间；
- 优先优化“卡脖子”环节，而不是均匀用力。

### 3. 五环节杠杆点

- 获客：渠道矩阵、内容钩子、转介绍、投放；
- 激活：首单/首用体验、新手引导、即时价值感；
- 留存：分层运营（RFM）、触达节奏、会员/订阅、唤醒流失；
- 复购：产品矩阵、组合套餐、周期性需求绑定；
- 转介绍：利益激励、社交货币、邀请机制。

### 4. 私域公域联动

- 公域负责拉新，私域（微信、社群、企业微信）负责留存与复购；
- 私域不是“发广告的地方”，而是“交付价值、建立信任、承接复购”的场。

## 四、适用场景与边界

- 适用：产品已验证、进入增长期；有一定存量用户；私域公域联动；
- 不适用：产品未验证、方向未确认时（先做需求验证与定位）；无复购逻辑的一次性买卖（重点放在获客转化，飞轮意义有限）。

## 五、常用指标与检查项

- 北极星指标趋势、漏斗各环节转化率；
- CAC（获客成本）、LTV（用户终身价值）、LTV/CAC；
- 复购率、留存曲线、转介绍率、NPS；
- 检查：增长动作是否都可归因到某个环节？飞轮转一圈的时间是否在缩短？

## 六、与其他方法论的关系

- 增长的前提是产品与需求成立（替代物性价比法/定位法）；
- 增长动作的验证依赖数据驱动与实验优化；
- 高信任行业的增长依赖内容营销先积累信任。
