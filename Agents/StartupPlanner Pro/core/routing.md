# v3 路由协议

路由顺序固定为：槽位提取 → 复合任务拆分 → 候选召回 → 硬过滤 → 多维评分 → 冲突裁决。

- “从 0 到 1”默认只是 `launch` 阶段，不能单独触发创业方向门。
- `do_not_use_when` 或 route `negative_signals` 命中时排除候选。
- 得分低于 0.70，或前两名分差小于 0.10 且职责存在实质差异时，只问一个关键问题。
- 每个原子任务只有一个权威生产者；复合请求可以形成多个带依赖的任务。
- 选择必须返回命中维度、置信度、备选者和淘汰原因。

评分：任务类型 30%、能力 25%、领域 15%、产物 15%、渠道 10%、生命周期 5%。
