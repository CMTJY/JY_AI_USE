# TRAE StartupPlanner Bootstrap

1. 读取 `Agents/StartupPlanner Pro/core/BOOTSTRAP.md`；
2. 只加载命中角色和任务需要的技能；
3. TRAE Multi Agents 可用时执行真实 Task Packet 委派；
4. 不可用时标记“单 Agent 串行角色模拟”；
5. 输出路由决定、产物、验证和实际参与角色。

本技能只负责入口，不复制团队路由、角色或工作流正文。
