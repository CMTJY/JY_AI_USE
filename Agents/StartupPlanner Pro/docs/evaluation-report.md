## 已知限制

- 宿主模型可能不完全遵循纯 Markdown/YAML 协议；
- 平台原生多 Agent、规则发现和权限不同；
- 自动生成的契约正例与真实用户分布不同，需要持续加入生产失败样本；
- 渠道规则和平台政策会变化，事实性建议仍需联网核验；
- 离线规则结果不等于三平台实机结果。
