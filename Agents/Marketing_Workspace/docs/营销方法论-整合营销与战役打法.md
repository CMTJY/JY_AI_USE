# 营销方法论：整合营销与战役打法

> 状态：已收录（主控原创整理，2026-08-07）
> 来源：整合营销传播（IMC）、事件营销与战役操盘经验

## 一、一句话总结

围绕一个核心创意，在多个触点同步、有节奏地发力，打一场有声量、有话题、有转化的营销战役——单点撒网不如一次集中引爆。

## 二、底层逻辑

- 单点传播声量有限：同一信息在多个触点重复出现，才会被记住；
- 用户接触路径是散的：社交、搜索、电商、线下、口碑构成完整旅程，各触点要承接同一主题；
- 战役的本质是“制造关注”：好创意 + 好话题 + 好承接，三者缺一不可；
- 事件/借势是放大器：让用户愿意讨论和转发，比广告自说自话更有穿透力。

## 三、核心框架

### 1. 战役五步

1. 目标：一次战役只定一个主目标（声量、拉新、转化、焕新）；
2. 人群：明确核心人群与传播受众（可以是两层）；
3. 洞察与创意：一句话核心创意，能让人记住并愿意讨论；
4. 触点矩阵与预算：按目标分配渠道（社交、KOL、投放、PR、线下、私域），算清每渠道的预期贡献；
5. 节奏与承接：预热 → 引爆 → 承接转化 → 复盘。

### 2. 创意三要素

- 相关性：和目标人群、产品强相关；
- 原创性：让人眼前一亮，不照搬；
- 冲击力：三秒内让人明白并产生情绪。

### 3. 发布节奏

- 预热期：制造悬念、预告、蓄水（低成本触点先行）；
- 引爆期：核心创意集中上线，KOL/事件同步发声；
- 承接期：流量进来后接得住——落地页、私域、客服、库存、优惠都已就位；
- 复盘期：按目标逐项盘点声量与转化，沉淀经验。

## 四、适用场景与边界

- 适用：新品上市、大促节点、品牌焕新、需要声量的关键时刻；
- 不适用：小预算日常运营（先聚焦单渠道做透，不要强行铺大场面）；没有承接能力时打战役是浪费钱；
- 注意：战役花钱快，必须预算封顶、节奏可控、承接到位，不做“为热闹而热闹”。

## 五、常用指标与检查项

- 声量：曝光、话题讨论、UGC、热搜/搜索提升；
- 互动：互动率、分享率、CPE（单次互动成本）；
- 转化：到店/进线、成交、新增私域；
- 检查：创意是否三要素齐全？各触点是否同一主题？承接是否就位？预算是否封顶？

## 六、与其他方法论的关系

- 战役引爆的是定位与品牌资产（配合定位法/品牌溢价法）；
- 战役的流量要进入增长飞轮承接留存复购（增长飞轮法）；
- 战役效果用数据驱动法归因复盘。
