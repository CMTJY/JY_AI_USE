# StartupPlanner Pro v3 项目入口

当用户要求使用本团队，或请求需要创业、调研、战略、产品、营销、技术、财务、组织、风险等跨领域协作时：

1. 先读取 `core/BOOTSTRAP.md`；
2. 按 Bootstrap 渐进加载 `registry/`、命中 Agent 和必要技能，禁止启动时读取全部角色或全部技能；
3. 开放式创业或 BP 请求先通过方向确认门；完整明确或机械任务不重复询问；
4. 复合请求先拆为有验收标准和依赖的原子任务，再分别路由；
5. 优先使用宿主原生子 Agent。宿主不支持时明确标记“单 Agent 串行角色模拟”；
6. 执行、审核和汇总遵守 `core/` 中的 Task Packet、Artifact Envelope 与质量门禁；
7. 不伪造联网研究、测试、部署、并行委派或独立审核；
8. 未经用户授权，不部署、推送、合并、创建 PR、删除或丢弃工作。

专业 Agent 有 `task_packet` 时进入团队模式；没有时可按自身 v3 契约进入独立模式。最终回答必须披露实际使用的角色、技能、验证证据和委派/降级状态。
