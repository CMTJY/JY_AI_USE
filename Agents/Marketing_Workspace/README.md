# Marketing_Workspace — 营销工作区

> 配套 StartupPlanner Pro 的市场专家：承接从市场调研到销售转化的完整营销任务，交付可执行、可衡量、能带来营收的方案。

## 团队定位

Marketing_Workspace 是一个方法论驱动的职业营销专家工作区。它不像通用聊天机器人那样"凭感觉回答"，而是：

- 每次行动前先查询 `docs/INDEX.md`，按任务类型匹配方法论；
- 以方法论为准绳完成需求拆解、方案输出、委派审核、数据核对与复盘总结；
- 方法论未覆盖时，以 10 年+ 多行业实战经验的专家能力行动，并把新打法总结入库。

它与 StartupPlanner Pro 的分工是：StartupPlanner 输出"做什么、为什么"，营销工作区承接"怎么打、怎么转化"。

## 核心能力

| 能力域 | 覆盖内容 |
| --- | --- |
| 市场调研 | 行业分析、竞品分析、用户画像 |
| 定位策略 | 定位与差异化、品牌溢价、STP 框架 |
| 内容创意 | 文案、创意、脚本、视觉方向 |
| 投放执行 | 渠道选择、预算分配、投放与转化方案 |
| 增长运营 | 增长飞轮、漏斗模型、私域运营 |
| 销售转化 | 从 0 到 1 验证渠道、电商、B2B 成交 |
| 数据复盘 | 指标测算、归因分析、实验优化 |

## 使用方法

把本目录放在当前 AI 工具可读取的项目范围内，在新对话中输入：

```text
请读取 ./Agents/Marketing_Workspace/AGENTS.md，然后：
为我的跨境电商产品制定一份完整的营销方案，目标市场美国，预算 5 万元。
```

开放型任务会先确认方向（目标市场、受众、产品/服务、渠道、预算、时间），不会擅自替用户定案；方向完整时直接执行。

## 目录结构

```text
Marketing_Workspace/
├── README.md                    # 本文件（项目总览）
├── AGENTS.md                    # 营销工作区主控协议
└── docs/
    ├── INDEX.md                 # 方法论库索引（每次行动前必查）
    └── 营销方法论-*.md          # 具体方法论文档
```

按 `AGENTS.md` 约定，承接任务后还会按需创建任务工作区：

```text
00_项目控制 → 01_市场研究 → 02_策略方案 → 03_内容创意
→ 04_投放执行 → 05_数据分析 → 06_最终交付 → 07_审核记录
```

## 与 StartupPlanner Pro 的关系

- StartupPlanner Pro 负责从零生成商业计划（战略、产品、财务、组织）；
- Marketing_Workspace 承接其中的营销落地：调研、定位、内容、投放、增长与转化；
- 需要子智能体协作时，按 `../StartupPlanner Pro/AGENTS.md` 的委派协议调用，并带验收标准审核产出。

## 工作流程

```text
用户任务 → 查询方法论索引 → 明确目标/受众/预算/交付物/验收标准
→（按需委派 StartupPlanner 子智能体）→ 审核产出（不合格退回）
→ 交付 + 汇报（结论/交付物/证据/假设/风险/下一步）
```

## 安全边界

- 真实资金投放、对外发布、报价合同、联系外部人员等操作必须先获得用户确认；
- 不虚构数据、反馈、合同或成交记录；
- 密钥、令牌、个人隐私不写入任何文档。
