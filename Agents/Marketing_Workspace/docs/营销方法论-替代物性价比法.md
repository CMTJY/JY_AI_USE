# 营销方法论：替代物性价比法

> 状态：已收录（用户提供，主控以营销专家身份评审通过，作为工作区可选方法论之一）
> 来源：用户根据视频自行整理的营销思维，2026-08-07 提供
> 评审结论：框架成立，适用于细分利基生意、个体生意与服务型业务的冷启动；不适用于品牌溢价、品类创新、大规模增长等场景。

## 一、一句话总结

不需要做全世界最好的产品，也不需要说服所有人。你只需要让一个具体的人相信，你的产品比他正在用的替代物更有性价比，交易就能成立。

## 二、底层逻辑

### 生意的本质

- 生意就是买卖：我卖一个产品，你买了，交易成立。
- 产品可以是实体（水晶、咖啡、炸鸡腿），也可以是虚拟（咨询、陪聊、课程）。
- 交易只跟两个人有关：只要用户认可你，生意就成立。
- 不需要说服所有人，只需要说服一个具体的用户。

### 定价的核心原理

- 价格不取决于成本，而取决于用户眼中的价值。
- 用户眼中的价值约等于他获得“最接近可替代物”所需支付的费用，也就是他的心理价格锚点。
- 示例：想在非洲卖山寨手机，当地最便宜的智能机是三星 Galaxy，卖 300 美金，那用户心中智能手机的价值锚点就是 300 美金。卖 100 美金不仅不贵，反而觉得便宜。

## 三、成交的两个关键

### 1. 性价比更高

- 功能接近，价格更低；
- 功能更好，价格接近。
- 不需要同时做到“价格更低 + 功能更好”。功能已经更好时，价格没必要再低。

### 2. 让用户相信

- 用用户正在使用的替代物判断他的认知水平（行为比语言诚实）。
- 用户不会主动说自己认知低，但他正在用的替代物直接暴露了他的认知水平和愿意支付的价格。
- 能指出他正在用替代物的问题，意味着你的认知高于他，专家人设就立住了，产品自然好卖。
- 实操示例：帮老板做个人 IP 时，不问他对 IP 的看法，而是问“稿子谁在写、给多少钱”。如果他在用 211 应届生写稿、月薪 6000，他的价格锚点就是 6000 左右，不会为 IP 写稿付 2 万/月。与其费力改变认知，不如找一个已经在付 2 万/月的老板来服务。

## 四、怎么起步

### 有产品

- 找一个具体用户 → 看他在用什么替代方案 → 把替代品当靶子 → 持续说明你的产品性价比更高。
- 渠道：线下说、发朋友圈、发短视频。短视频不是拍给所有人看，而是拍给最想成交的那一个人看。

### 没有产品

- 在网上找一款已经卖爆的产品当“替代物”，通过提升性价比做出你的版本：
  1. 从 1688 找更便宜的货源（做女装、珠宝常用）；
  2. 只保留核心功能来压价（做教培、K12 常用）；
  3. 同等价格下提供更好的包装或附加内容（做疗愈周边、AI 工具常用）。
- 然后用各种方式告诉已经在用替代品的用户，你的产品好在哪里。

## 五、专家评估（主控批注）

### 站得住的部分

- 锚定替代物定价等于价值定价加参照价格，符合定价实践与行为经济学；
- 从用户正在用的替代物判断支付意愿属于“揭示性偏好”，比问卷访谈更诚实，也是筛选合格客户的最快方法；
- “性价比两条路径”避免“又便宜又好”的过度内卷，防止产品过度设计；
- 有产品 / 没有产品两条起步路径是跟款加货源优化的实操打法，对个体电商和细分市场冷启动成立。

### 必须打补丁的部分

1. “一个具体的人”应理解为“一个具体的用户画像 / 细分人群（ICP）”，不是字面上的一个客户。成交靠一个人，生意靠一群人；规模来自可复制的标准打法。
2. 性价比打法有天花板：长期只拼性价比会陷入价格战，不积累品牌、复购和信任资产。替代物当靶子适合冷启动，不适合建立护城河。
3. 锚点会漂移：竞品、市场环境和用户消费能力变化后，锚点必须定期重测，不能假设一成不变。
4. 存在合规边界：跟款和对比替代物在知识产权、商标、专利、广告法（对比广告与虚假宣传）上有风险，涉及前必须核实。
5. 只覆盖“获客 + 首单成交”，缺复购、留存、转介绍和 LTV（用户终身价值）设计；正式生意模型必须补上全生命周期。

### 适用边界

- 优先使用：细分利基市场、个体/小生意冷启动、服务型业务（咨询、IP、课程）、电商跟款、客单价中低的信任品。
- 换用其他框架：品牌溢价与品类创新、大品牌大规模投放、B2B 复杂销售周期、平台型/网络效应生意、需要长期护城河的项目。

## 六、使用方式（对主控的要求）

- 本方法论是工具库之一，不是唯一真理；不得在任何任务中机械套用。
- 使用前先判断任务类型是否落在“细分生意 / 冷启动”适用范围内。
- 使用时必须同时检查：目标人群是否具体到可画像、替代物是否明确、锚点是否有证据、性价比路径是否只选了一条、是否补了复购与留存设计、合规边界是否核实。
- 与 StartupPlanner Pro 的调研、财务角色配合时，把本方法论的假设交给子智能体验证（锚点价格、替代物市场份额、货源成本等）。
