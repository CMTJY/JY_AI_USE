# 营销方法论：定位与差异化

> 状态：已收录（主控原创整理，2026-08-07）
> 来源：定位理论（特劳特/里斯）、STP 框架与多行业营销实战经验

## 一、一句话总结

在用户心智中占据一个独特、可信、值得付溢价的位置；差异化不是“比别人更好”，而是“不同且相关”。

## 二、底层逻辑

- 用户心智容量有限且厌恶混乱：一个品类里，用户通常只能记住一两个名字，第一胜过最好；
- 用户按品类思考：选购时先想“这是什么品类”，再想“这个品类里选谁”；
- 差异化来源有五个维度：产品、价格、渠道、服务体验、品牌故事/情感；
- 定位不是自己声称的，而是用户心智里最终形成的印象；传播只是把定位送达用户。

## 三、核心框架

### 1. STP 三步

- 细分（Segmentation）：按人群、场景、价格带、需求强弱切分市场，找到结构性机会；
- 目标（Targeting）：选择最能赢、最有价值的细分市场，明确目标用户画像（ICP）；
- 定位（Positioning）：为这个细分市场设计独特价值主张。

### 2. 定位声明公式

```text
For [目标用户], who [未被满足的需求],
[品牌/产品] is [品类] that [差异化利益],
unlike [主要替代/竞品], we [支持点/证据].
```

### 3. 差异化验证三问

- 相关吗：目标用户在不在乎这个差异？
- 可信吗：有没有产品、服务或数据支持？
- 可持续吗：竞品模仿的成本高不高？

### 4. 落地动作

- 一句话定位 + 一个核心视觉符号 + 一套统一话术；
- 所有触点（包装、内容、销售话术、客服）重复同一心智信息；
- 用传播、案例、权威背书不断加固，而不是频繁换定位。

## 四、适用场景与边界

- 适用：存量竞争市场、同质化品类、要溢价与差异化、品牌需要立足点；
- 不适用：零需求新品类冷启动（需求验证优先于定位，先用替代物性价比法）；纯拼价格的流量生意（定位救不了成本劣势）；
- 注意：定位清晰不代表产品有需求，先验证需求再谈定位。

## 五、常用指标与检查项

- 心智份额：无提示/提示下品牌提及率；
- 品类联想：提到品类时是否首先想到本品牌；
- 溢价能力：相对主要替代物的价格溢价与销量变化；
- 传播一致性：各触点话术是否围绕同一心智信息。

## 六、与其他方法论的关系

- 冷启动期先验证需求（替代物性价比法），需求成立后做定位；
- 定位是品牌资产（品牌溢价法）的地基；
- 定位落地依赖内容营销与整合战役持续传播。
