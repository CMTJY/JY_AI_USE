# 营销方法论库索引

> 本索引是营销工作区所有营销行动的出发点。主控每次行动前必须查询本索引，命中后读取对应方法论文档；未命中时以专家能力行动，并在任务完成后总结入库。

## 一、使用规则

1. 每次行动（需求拆解、方案输出、委派子智能体、核对数据、审核产物、复盘总结）前，先查询本索引。
2. 按任务类型匹配 1 个主方法论；必要时可组合 1-2 个辅助方法论，但必须说明组合理由。
3. 命中后读取 `docs/` 下对应文档，全程以方法论为准绳进行输出、调用、核对和复查。
4. 未命中或直接套用会误导时：主控以职业营销专家能力行动，任务完成后把可复用打法总结成新方法论文档入库。

| 方法论 | 一句话 | 适用场景 | 不适用场景 |
| --- | --- | --- | --- |
| [替代物性价比法](营销方法论-替代物性价比法.md) | 让一个具体用户相信你的产品比他正在用的替代物更值 | 细分利基、个体生意冷启动、跟款、服务型业务 | 品牌溢价、品类创新、大规模投放、需要护城河的长期生意 |
| [定位与差异化](营销方法论-定位与差异化.md) | 在用户心智中占据一个独特、可信的位置 | 存量竞争、同质化品类、溢价定位 | 零需求新品类冷启动 |
| [增长飞轮与漏斗模型](营销方法论-增长飞轮与漏斗模型.md) | 把获客到转介绍做成可复利的系统 | 已验证产品进入增长期、私域公域联动 | 产品未验证、方向未确认 |

| [整合营销与战役打法](营销方法论-整合营销与战役打法.md) | 围绕核心创意多触点同步发力，打有节奏的战役 | 新品上市、大促节点、品牌焕新、要声量 | 小预算日常运营 |

## 四、进化机制

- 入库条件：至少一次实战验证、具备可复用性、与现有文档不重复。
- 入库格式：一句话总结 / 底层逻辑 / 核心框架 / 适用场景与边界 / 常用指标与检查项 / 与其他方法论的关系。
- 入库流程：主控在任务完成后总结 → 以 `营销方法论-短名称.md` 命名存入 `docs/` → 更新本索引（一览表与组合规则）→ 在任务汇报中说明新增方法论与依据。
- 修订条件：现有方法论在实战中失效或发现更优做法时，主控修订对应文档并注明修订日期与原因，保留旧结论记录。

## 五、使用检查项（每次行动后自查）

- [ ] 是否已查询本索引并命中方法论？
- [ ] 输出、委派、核对、审核是否以方法论为准绳？
- [ ] 未命中时是否以专家能力行动并说明原因？
- [ ] 任务中是否出现可复用新打法且已完成入库？
